## Task 1: Student Management API

**Status: Completed**

Developed a Student Management API using Flask and SQLite, with a Streamlit user interface.

### Features

- Create student records
- View student records
- Update student information
- Delete student records

### How to Run

**1. Start the Flask API:**

```bash
python .\Task1\App.py
```

**2. Open another terminal and start Streamlit:**

```bash
python -m streamlit run .\Task1\streamlit_app.py
```

**3. Open the application:**

```text
http://localhost:8501
```
